# Capturas de HABLA Studio

Las imágenes muestran la versión web final ejecutada en una vista previa local con la identidad ficticia de desarrollo y progreso creado por las comprobaciones de navegador. No contienen perfiles ni bases de datos de usuarios reales.

- `habla-desktop.png`: recorrido de Python en una pantalla de escritorio.
- `habla-laboratory.png`: instrucciones, entradas, editor Python y ejecución correcta de sus casos.
- `habla-mobile.png`: el mismo recorrido en una ventana de 390 px de ancho.
- `habla-cover.svg`: portada del repositorio, construida en SVG; no es una captura de la aplicación.

Las capturas se obtuvieron con Playwright y Microsoft Edge en modo headless. El tamaño de ventana permite comprobar la presentación adaptable; no representa una prueba en un dispositivo físico.
