# Habla · Python y SQL

Versión web de Habla para Sites, con 72 lecciones y 576 ejercicios. El diseño Habla Studio usa tipografía del sistema, superficies claras y una navegación adaptable. Guarda perfiles, respuestas, borradores y XP en D1. Todas las lecciones SQL y Python están disponibles desde el principio: completar una lección nunca es requisito para abrir otra.

La siguiente recomendada es la primera lección pendiente en el orden del curso. Retomar un intento reciente es una opción independiente. Los enlaces del recorrido, las direcciones directas y la navegación anterior/siguiente permiten saltar sin aprobar.

No se cambia el esquema ni se modifica el catálogo. Los registros parcialmente inválidos se leen de forma defensiva, conservando los campos originales recuperables dentro del registro privado antes de una escritura posterior. Si un registro completo no es JSON válido, no se sobrescribe: el curso y sus materiales siguen disponibles y se informa de que el progreso no se puede leer.

Cuando falla el guardado se puede practicar sin guardar. Esta ronda es temporal, no concede XP ni sustituye los datos de D1 y usa el mismo corrector. Se avisa de que hay que mantener la pestaña abierta; los resultados de esa ronda no se sincronizan después. Si no hay conexión con el servidor, tampoco puede funcionar el corrector de respuestas normales. No se promete funcionamiento completamente sin conexión.

Cada visitante entra con ChatGPT. La identidad se obtiene exclusivamente de las cabeceras verificadas por Sites. Los intentos siempre se consultan con el identificador del propietario; las escrituras rechazan peticiones de otros orígenes y usan actualizaciones atómicas con revisión para evitar pérdidas o recompensas duplicadas entre dispositivos.

El panel `/admin` consulta un resumen del aprendizaje de quienes han elegido compartirlo. Los participantes leen el aviso antes de continuar y pueden dejar de compartir desde Perfil; quienes ya usaban Habla no aparecen hasta que lo acepten. No se exponen correos, respuestas ni borradores en este panel. El permiso del creador se calcula en el servidor comparando la identidad verificada con `HABLA_OWNER_USER_ID`, configurado como secreto de Sites; nunca se obtiene del nombre, correo, navegador o campos del perfil. La variable debe contener el ID específico de este Site. Si falta, el panel rechaza el acceso. El archivo ignorado `.dev.vars` solo contiene la identidad ficticia de pruebas locales y no debe publicarse.

`scripts/check-creator.mjs` comprueba autorización y consultas sobre una base desechable; `scripts/check-creator-browser.cjs` comprueba el aviso, el panel móvil, la retirada de la elección y la conservación del progreso. Esta ampliación no cambia el esquema ni reinicia los avances.

Python y SQLite se ejecutan con Pyodide 0.29.2 en un Web Worker del navegador, con límites de ejecución y datos desechables. Nunca se ejecuta código del visitante en el servidor ni se le da acceso a D1. El servidor compara los resultados reportados con casos precalculados; este laboratorio de autoaprendizaje no es una evaluación certificada y no ofrece protección frente a un alumno que manipule sus propios resultados.

El primer uso del laboratorio descarga su entorno desde el CDN de Pyodide. Requiere conexión y un navegador moderno con WebAssembly. El almacenamiento local solo conserva preferencias y una copia temporal del borrador pendiente; D1 es la fuente de verdad del progreso.

No se han subido bases de datos locales, sesiones, contraseñas ni perfiles. El progreso local sigue en la instalación original: esta publicación empieza con un perfil propio de Sites. Mantener la misma cuenta de ChatGPT permite retomar el avance de esta publicación desde el móvil u otro navegador.

La configuración de alojamiento está en `.openai/hosting.json`; las migraciones de esquema están en `drizzle/`. No editar migraciones ya aplicadas. Desarrollo: `npm run dev`. Compilación: `npm run build`.

Validación: `scripts/check-access.mjs` prueba las 72 lecciones con perfiles nuevos, existentes y dañados sobre una base aislada, fallos de almacenamiento y conservación del catálogo. `scripts/check-studio.cjs` prueba navegación libre, teclado, ausencia de progreso, práctica sin guardar, contraste de texto sobre fondos sólidos y anchos de 320–1920 px. `scripts/check-cloud.cjs`, `scripts/check-review.cjs`, `scripts/check-creator.mjs` y `scripts/check-creator-browser.cjs` cubren el laboratorio, los borradores, la idempotencia y la privacidad. Ejecutar las pruebas de navegador en serie: utilizan exclusivamente el perfil ficticio de la vista previa local y algunas añaden respuestas de prueba. No ejecutar contra producción. No equivalen a pruebas en dispositivos físicos ni a una auditoría completa con lectores de pantalla.

Revisión docente de octubre de 2026: 265 ejercicios de código incluyen entradas o tablas visibles, ejemplos esperados y el contrato del corrector. Las primeras seis lecciones SQL están en español y evitan distractores que sí son válidos en SQLite. `scripts/curriculum-review.mjs` contiene las correcciones manuales; `scripts/refine-curriculum.mjs` genera los datos explicativos y recalcula los resultados de referencia sin leer ni modificar perfiles. `scripts/export-curriculum.mjs` vuelve a aplicar esa revisión al exportar. `scripts/check-review.cjs` comprueba todas las soluciones en el navegador, alternativas válidas, errores habituales, borradores y continuidad entre dispositivos. Los identificadores de lección y ejercicio y el esquema D1 se conservan.
